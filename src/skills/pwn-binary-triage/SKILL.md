# Binary / ELF 二进制基础分析流程

## 1. 静态属性与保护检查
- 使用 `file` 确认目标架构（x86 / x86_64 / ARM）及链接方式。
- 使用 `checksec` 查看 RELRO、Canary、NX、PIE 状态并记录 `libc` 版本。
- 用 `strings` 和符号表检查关键字符串与导入函数。

## 2. 输入路径与边界核查
- 定位所有用户输入点，核对缓冲区容量与读取长度限制。
- 梳理栈帧与堆块分配释放流程，确认边界条件与指针生命周期。

## 3. 本地验证
- 在隔离调试环境中验证偏移和状态，整理可复现脚本。
